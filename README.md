# 聖佳冷凍材料　線上詢價（示範版）

新北市中和的冷凍空調材料行「聖佳冷凍材料」的線上詢價網站示範。網站不標價格：客人挑好品項、填數量，按一下就把整張詢價單帶進 LINE，店家在 LINE 回覆報價。

- 網站：<https://xiaoyu-1201.github.io/shengjia-inquiry/>
- 商品照片是 AI 示意圖，商品與內容皆為示範。

## 功能

- 商品分類、搜尋、常用清單、最近看過
- 詢價單：一次挑多樣、改數量，用 LINE 傳出（店家 LINE 官方帳號開通後啟用，目前是示範模式）
- 壓縮機型號查詢：18 家品牌、436 個型號，可以打型號搜尋
- 問過的清單（只存在客人自己的手機）、關於我們、常見問題
- 手機版優化

## 資料夾

| 位置 | 內容 |
|---|---|
| `index.html` | 網站（單一檔案，不需要建置） |

| `qr/` | 詢價網站 QR code（貼文、限動藍底、限動白底、IG 風格） |
| `promo/` | 宣傳片原始檔：`promo.html` 動畫、`render.mjs` 逐格輸出、`mix.py` 配樂與音效合成、`beats.py` 節拍分析、`capture.mjs` 網站截圖 |
